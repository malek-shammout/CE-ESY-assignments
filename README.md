# حل الواجب الأول: تنفيذ المخزن الدائري (Circular Buffer)

## وصف بسيط للحل
هذا المشروع هو تطبيق عملي لمفهوم "المخزن الدائري" بلغة C، تم تنفيذه يدوياً بالكامل دون استخدام أي مكتبات أو هياكل بيانات جاهزة.

تم بناء الحل بالاعتماد على النقاط التالية:
* **بنية البيانات (Struct):** تم استخدام `struct` لجمع عناصر المخزن معاً، وهي تحتوي على: مصفوفة لتخزين الحروف، مؤشر للكتابة `tail`، مؤشر للقراءة `head`، وعداد لمعرفة عدد العناصر الحالية `count`.
* **المنطق الدائري:** لجعل المصفوفة دائرية، تم استخدام عملية باقي القسمة (`% SIZE`) عند زيادة مؤشرات القراءة والكتابة، مما يضمن عودة المؤشر إلى البداية (الصفر) بمجرد وصوله إلى نهاية المصفوفة.
* **الحالات الحدية:** 
  * تم تأمين المخزن ضد الكتابة الزائدة (Overflow) باستخدام دالة `isFull`.
  * تم تأمين المخزن ضد القراءة الفارغة (Underflow) باستخدام دالة `isEmpty`.

## مسار عمل البرنامج (في الدالة `main`)
1. يطلب البرنامج من المستخدم إدخال اسمه.
2. يتم استخدام دالة `strcat` لإضافة النص "CE-ESY" إلى نهاية الاسم.
3. يتم إدخال (كتابة) النص الناتج حرفاً بحرف إلى المخزن الدائري.
4. يتم قراءة البيانات مرة أخرى من المخزن وطباعتها على الشاشة.
5. في النهاية، يتم فحص المخزن وطباعة رسالة تؤكد أنه أصبح فارغاً تماماً بعد عملية القراءة.
